# oracle_test.sql

This document describes the `oracle_test.sql` script, which serves as a sample script for creating and populating a table in an Oracle database.

## File Purpose

The script performs a sequence of setup, data manipulation, and verification steps. It is designed to be run in a SQL*Plus environment. Its primary actions are:
1.  Configuring the SQL*Plus session for verbose output.
2.  Creating a new table named `github_projects`.
3.  Inserting three sample rows of data into the new table.
4.  Committing the transaction.
5.  Querying the table to display the inserted data.
6.  Printing a confirmation message to the console upon successful completion.

## Tables

### `github_projects`

This table is created by the script to store basic information about software projects.

**Schema Definition:**

| Column | Type | Constraints | Description |
| --- | --- | --- | --- |
| `project_id` | `NUMBER` | `GENERATED BY DEFAULT AS IDENTITY`, `PRIMARY KEY` | A system-generated unique identifier for the project. |
| `project_name` | `VARCHAR2(100)` | `NOT NULL` | The name of the project. |
| `language` | `VARCHAR2(50)` | | The primary programming language of the project. |
| `created_date` | `DATE` | `DEFAULT SYSDATE` | The date the record was created, defaulting to the current system date. |

## Script Behavior

The script executes sequentially and does not define any reusable functions or procedures.

### Environment Setup

The script begins by setting two standard SQL*Plus environment variables:
- `SET ECHO ON;`: Displays the SQL commands on screen as they are executed.
- `SET SERVEROUTPUT ON;`: Enables the `DBMS_OUTPUT` buffer to display output from PL/SQL blocks.

### Data Manipulation

1.  **Table Creation**: A `CREATE TABLE` statement is executed to define the `github_projects` table schema as detailed above.
2.  **Data Insertion**: Three `INSERT` statements are run to populate the table with sample data:
    - `('Sample Perl Script', 'Perl')`
    - `('Sample Shell Script', 'Bash')`
    - `('Sample Oracle Script', 'SQL')`
3.  **Transaction Commit**: A `COMMIT;` command is executed to save the data insertions permanently to the database.

### Verification and Output

1.  **Query**: A `SELECT` statement queries all records from the `github_projects` table. It formats the `created_date` column as a 'YYYY-MM-DD' string for display.
2.  **Success Message**: An anonymous PL/SQL block uses `DBMS_OUTPUT.PUT_LINE` to print a multi-line success message to the console, confirming that the script's operations were successful.
