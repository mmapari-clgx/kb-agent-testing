# oracle_test.sql

This document provides technical documentation for the `oracle_test.sql` script (internally referenced in its header as `hello_github.sql`). This script is a sample Oracle SQL utility designed to set up a basic table, populate it with sample data, verify the insertion, and output a success confirmation.

---

## Overview

The script performs the following high-level actions:
1. Configures the SQL*Plus environment.
2. Creates a sample table named `github_projects`.
3. Inserts four sample records representing different scripts/languages.
4. Commits the transaction.
5. Queries the newly inserted data to verify successful execution.
6. Executes an anonymous PL/SQL block to print a success message to the server output.

---

## Environment Configuration

The script configures the following SQL*Plus environment variables at startup:
* **`SET ECHO ON;`**: Displays the SQL commands on the screen as they are executed.
* **`SET SERVEROUTPUT ON;`**: Enables the retrieval and display of output generated by PL/SQL blocks (specifically `DBMS_OUTPUT.PUT_LINE` statements).

---

## Database Objects

### Tables

#### `github_projects`
This table stores metadata about sample projects.

| Column Name | Data Type | Constraints | Default Value | Description |
| :--- | :--- | :--- | :--- | :--- |
| `project_id` | `NUMBER` | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | *N/A* | Unique identifier for each project. |
| `project_name` | `VARCHAR2(100)` | `NOT NULL` | *N/A* | The name of the project. |
| `language` | `VARCHAR2(50)` | *None* | *N/A* | The programming or scripting language used. |
| `created_date` | `DATE` | *None* | `SYSDATE` | The timestamp when the record was created. |

---

## Execution Flow and Behavior

### 1. Table Creation
The script attempts to create the `github_projects` table with the schema defined above.

### 2. Data Insertion
Four sample records are inserted into the `github_projects` table:

| project_name | language |
| :--- | :--- |
| `Sample Perl Script` | `Perl` |
| `Sample Shell Script` | `Bash` |
| `Sample Oracle Script` | `SQL` |
| `Sample PLSQL Script` | `SQL` |

### 3. Transaction Control
A `COMMIT;` statement is executed to persist the inserted records to the database.

### 4. Verification Query
The script executes a `SELECT` query to retrieve and display all records from the `github_projects` table. The `created_date` column is formatted to `YYYY-MM-DD` and aliased as `created_on`:

```sql
SELECT project_id, project_name, language, TO_CHAR(created_date, 'YYYY-MM-DD') AS created_on
FROM github_projects;
```

### 5. Success Confirmation
An anonymous PL/SQL block executes to output a success message to the console:

```text
----------------------------------------------------
Sample data inserted and queried successfully!
Hello, GitHub!
----------------------------------------------------
```
