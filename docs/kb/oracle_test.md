# oracle_test.sql

This document provides technical documentation for the `oracle_test.sql` script (internally referred to in comments as `hello_github.sql`). This script serves as a sample Oracle SQL utility to verify database connectivity, table creation, data insertion, and PL/SQL execution.

## Overview

The script performs the following high-level operations:
1. Configures the SQL*Plus environment.
2. Creates a sample table named `github_projects`.
3. Populates the table with sample records.
4. Commits the transaction.
5. Queries the table to verify the inserted data.
6. Executes an anonymous PL/SQL block to output a success message.

---

## Environment Configuration

The script configures the following SQL*Plus environment variables at the start of execution:

*   `SET ECHO ON;`: Displays the SQL commands on the screen as they are executed.
*   `SET SERVEROUTPUT ON;`: Enables the retrieval and display of output generated by the `DBMS_OUTPUT` package in PL/SQL blocks.

---

## Database Objects

### Tables

#### `github_projects`
A table designed to store metadata about sample projects.

| Column Name | Data Type | Constraints | Default Value | Description |
| :--- | :--- | :--- | :--- | :--- |
| `project_id` | `NUMBER` | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | *None* | Unique identifier for each project. |
| `project_name` | `VARCHAR2(100)` | `NOT NULL` | *None* | The name of the project. |
| `language` | `VARCHAR2(50)` | *None* | *None* | The programming or scripting language used. |
| `created_date` | `DATE` | *None* | `SYSDATE` | The timestamp when the record was created. |

---

## Execution Flow

### 1. Table Creation
The script drops no existing tables and attempts to create the `github_projects` table directly:
```sql
CREATE TABLE github_projects (
    project_id   NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    project_name VARCHAR2(100) NOT NULL,
    language     VARCHAR2(50),
    created_date DATE DEFAULT SYSDATE
);
```

### 2. Data Seeding
Four sample records are inserted into the `github_projects` table:

| project_name | language |
| :--- | :--- |
| 'Sample Perl Script' | 'Perl' |
| 'Sample Shell Script' | 'Bash' |
| 'Sample Oracle Script' | 'SQL' |
| 'Sample PLSQL Script' | 'SQL' |

### 3. Transaction Control
A explicit `COMMIT;` statement is executed to persist the inserted records to the database.

### 4. Verification Query
The script executes a `SELECT` statement to verify the data. The `created_date` column is formatted to a string using the format mask `YYYY-MM-DD`:
```sql
SELECT project_id, project_name, language, TO_CHAR(created_date, 'YYYY-MM-DD') AS created_on
FROM github_projects;
```

### 5. Success Notification
An anonymous PL/SQL block executes to print confirmation messages to the standard output:
```sql
BEGIN
    DBMS_OUTPUT.PUT_LINE('----------------------------------------------------');
    DBMS_OUTPUT.PUT_LINE('Sample data inserted and queried successfully!');
    DBMS_OUTPUT.PUT_LINE('Hello, GitHub!');
    DBMS_OUTPUT.PUT_LINE('----------------------------------------------------');
END;
/
```
