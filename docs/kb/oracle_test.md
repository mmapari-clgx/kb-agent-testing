# oracle_test.sql

This document provides technical documentation for the `oracle_test.sql` script (internally referred to in comments as `hello_github.sql`). 

## Overview

The `oracle_test.sql` script is a sample Oracle SQL and PL/SQL script designed to verify database connectivity, test basic DDL/DML operations, and demonstrate integration with GitHub. It configures the SQL*Plus environment, creates a sample table, populates it with test data, queries the results, and outputs a success message.

---

## Environment Configuration

The script configures the following SQL*Plus environment variables at the start of execution:

*   `SET ECHO ON;`: Displays the SQL commands on the screen as they are executed.
*   `SET SERVEROUTPUT ON;`: Enables the retrieval and display of output generated by PL/SQL blocks (specifically `DBMS_OUTPUT`).

---

## Database Objects

### `github_projects` (Table)

The script creates a single table to store sample project metadata.

#### Schema Definition

| Column Name | Data Type | Constraints | Default Value | Description |
| :--- | :--- | :--- | :--- | :--- |
| `project_id` | `NUMBER` | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | *N/A* | Unique identifier for each project. |
| `project_name` | `VARCHAR2(100)` | `NOT NULL` | *N/A* | The name of the project. |
| `language` | `VARCHAR2(50)` | *None* | *N/A* | The programming language used in the project. |
| `created_date` | `DATE` | *None* | `SYSDATE` | The date and time the record was created. |

---

## Execution Flow and Behavior

The script executes sequentially in the following phases:

### 1. Table Creation
The script drops no existing tables and attempts to create the `github_projects` table directly. 

### 2. Data Insertion
Four sample records are inserted into the `github_projects` table:

| project_name | language |
| :--- | :--- |
| Sample Perl Script | Perl |
| Sample Shell Script | Bash |
| Sample Oracle Script | SQL |
| Sample PLSQL Script | SQL |

### 3. Transaction Control
A `COMMIT;` statement is executed to persist the inserted records to the database.

### 4. Data Verification Query
The script executes a `SELECT` query to verify the inserted data. The `created_date` column is formatted to a string (`YYYY-MM-DD`) as `created_on`:

```sql
SELECT project_id, project_name, language, TO_CHAR(created_date, 'YYYY-MM-DD') AS created_on
FROM github_projects;
```

### 5. Success Notification (PL/SQL Block)
An anonymous PL/SQL block executes to print a success message to the server output console:

```text
----------------------------------------------------
Sample data inserted and queried successfully!
Hello, GitHub!
----------------------------------------------------
```
