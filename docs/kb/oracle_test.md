# oracle_test.sql

This document provides technical documentation for the `oracle_test.sql` script (internally referred to in comments as `hello_github.sql`). 

## Overview

The `oracle_test.sql` script is a sample Oracle SQL script designed to verify database connectivity, table creation, data manipulation, and PL/SQL execution. It sets up a standard SQL*Plus environment, creates a sample table, populates it with test data, queries the data to verify success, and outputs a confirmation message.

---

## Environment Configuration

The script configures the following SQL*Plus environment variables at the start of execution:

*   `SET ECHO ON;`: Displays the SQL commands in the output as they are executed.
*   `SET SERVEROUTPUT ON;`: Enables the retrieval and display of output generated by PL/SQL blocks (specifically `DBMS_OUTPUT`).

---

## Database Objects

### Table: `github_projects`

The script creates a single table to store sample project information.

#### Schema Definition

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `project_id` | `NUMBER` | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | Unique identifier for each project, auto-incremented by default. |
| `project_name` | `VARCHAR2(100)` | `NOT NULL` | The name of the project. |
| `language` | `VARCHAR2(50)` | None | The programming language used in the project. |
| `created_date` | `DATE` | `DEFAULT SYSDATE` | The date the record was created. Defaults to the current system date. |

---

## Execution Flow and Behavior

The script executes sequentially in the following phases:

### 1. Table Creation
The `github_projects` table is created using the schema defined above.

### 2. Data Insertion
Four sample records are inserted into the `github_projects` table:

| project_name | language |
| :--- | :--- |
| 'Sample Perl Script' | 'Perl' |
| 'Sample Shell Script' | 'Bash' |
| 'Sample Oracle Script' | 'SQL' |
| 'Sample PLSQL Script' | 'SQL' |

### 3. Transaction Commit
A `COMMIT;` statement is executed to persist the inserted records to the database.

### 4. Verification Query
The script executes a `SELECT` statement to retrieve and display the inserted records. The `created_date` column is formatted to `YYYY-MM-DD` and aliased as `created_on`:

```sql
SELECT project_id, project_name, language, TO_CHAR(created_date, 'YYYY-MM-DD') AS created_on
FROM github_projects;
```

### 5. Success Notification
An anonymous PL/SQL block executes to output a success message to the console using `DBMS_OUTPUT.PUT_LINE`:

```text
----------------------------------------------------
Sample data inserted and queried successfully!
Hello, GitHub!
----------------------------------------------------
```
