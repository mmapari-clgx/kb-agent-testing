# oracle_test.sql

This document provides technical documentation for the `oracle_test.sql` script (internally referenced in comments as `hello_github.sql`). This script serves as a sample Oracle SQL utility to initialize a test table, populate it with sample project data, verify the insertion, and output status messages.

## Overview

The script performs the following high-level operations:
1. Configures the SQL*Plus environment.
2. Creates a sample table named `github_projects`.
3. Inserts four sample records representing different script languages.
4. Commits the transaction.
5. Queries the table to verify the data.
6. Executes an anonymous PL/SQL block to print success messages to the server output.

---

## Environment Configuration

The script configures the SQL*Plus environment with the following settings:
*   `SET ECHO ON;`: Displays the SQL commands on the screen as they are executed.
*   `SET SERVEROUTPUT ON;`: Enables the retrieval and display of output generated by the `DBMS_OUTPUT` package in PL/SQL.

---

## Database Objects

### Table: `github_projects`

This table stores metadata about sample projects.

| Column Name | Data Type | Constraints | Default Value | Description |
| :--- | :--- | :--- | :--- | :--- |
| `project_id` | `NUMBER` | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | *N/A* | Unique identifier for each project. |
| `project_name` | `VARCHAR2(100)` | `NOT NULL` | *N/A* | The name of the project. |
| `language` | `VARCHAR2(50)` | None | *N/A* | The programming or scripting language used. |
| `created_date` | `DATE` | None | `SYSDATE` | The timestamp when the record was created. |

---

## Execution Flow

### 1. Table Creation
The script drops no existing tables and attempts to create the `github_projects` table directly:
```sql
CREATE TABLE github_projects (
    project_id   NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    project_name VARCHAR2(100) NOT NULL,
    language     VARCHAR2(50),
    created_date DATE DEFAULT SYSDATE
);
```

### 2. Data Insertion
Four sample records are inserted into the `github_projects` table:

| Project Name | Language |
| :--- | :--- |
| 'Sample Perl Script' | 'Perl' |
| 'Sample Shell Script' | 'Bash' |
| 'Sample Oracle Script' | 'SQL' |
| 'Sample PLSQL Script' | 'SQL' |

### 3. Transaction Control
A explicit `COMMIT;` statement is executed to persist the inserted records to the database.

### 4. Verification Query
To verify the data insertion, the script executes a `SELECT` query. The `created_date` column is formatted to a string using the format mask `YYYY-MM-DD`:
```sql
SELECT project_id, project_name, language, TO_CHAR(created_date, 'YYYY-MM-DD') AS created_on
FROM github_projects;
```

### 5. Status Output
An anonymous PL/SQL block executes to print confirmation messages to the console:
```sql
BEGIN
    DBMS_OUTPUT.PUT_LINE('----------------------------------------------------');
    DBMS_OUTPUT.PUT_LINE('Sample data inserted and queried successfully!');
    DBMS_OUTPUT.PUT_LINE('Hello, GitHub!');
    DBMS_OUTPUT.PUT_LINE('----------------------------------------------------');
END;
/
```
