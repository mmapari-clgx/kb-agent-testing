# oracle_test.sql

## Purpose

This script serves as a sample for demonstrating basic Oracle SQL operations. It handles environment setup, table creation, data insertion, transaction management, and data verification.

## Execution Behavior

The script executes a series of SQL and PL/SQL commands in the following order:

1.  **Environment Setup**: Configures the SQL*Plus session by setting `ECHO ON` (to display commands as they are executed) and `SERVEROUTPUT ON` (to enable output from `DBMS_OUTPUT`).

2.  **Table Creation**: Creates a new table named `github_projects`.

3.  **Data Insertion**: Inserts three sample records into the `github_projects` table.

4.  **Transaction Commit**: Commits the insertion transaction, making the data permanent.

5.  **Data Verification**: Queries all records from the `github_projects` table and displays them. The `created_date` column is formatted as `YYYY-MM-DD`.

6.  **Output Message**: Executes an anonymous PL/SQL block to print a formatted success message to the console using `DBMS_OUTPUT.PUT_LINE`.

## Objects Created

### Table: `github_projects`

The script creates a table to store information about sample GitHub projects.

**DDL:**
```sql
CREATE TABLE github_projects (
    project_id   NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    project_name VARCHAR2(100) NOT NULL,
    language     VARCHAR2(50),
    created_date DATE DEFAULT SYSDATE
);
```

**Columns:**

| Column | Type | Constraints | Description |
| --- | --- | --- | --- |
| `project_id` | `NUMBER` | `PRIMARY KEY` | A system-generated unique identifier for the project. It is an identity column. |
| `project_name` | `VARCHAR2(100)` | `NOT NULL` | The name of the project. Cannot be null. |
| `language` | `VARCHAR2(50)` | | The primary programming language used in the project. |
| `created_date` | `DATE` | `DEFAULT SYSDATE` | The date the record was created. Defaults to the current system date (`SYSDATE`) on insertion. |
