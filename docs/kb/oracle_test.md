# oracle_test.sql

This document provides technical documentation for the `oracle_test.sql` script (internally referred to in comments as `hello_github.sql`). 

## Overview

The `oracle_test.sql` script is a sample Oracle SQL script designed to demonstrate basic database operations, including table creation, data insertion, transaction management, querying, and PL/SQL console output. It serves as a verification or smoke-test script within the codebase.

---

## Environment Configuration

The script configures the following SQL*Plus environment variables at the start of execution:

*   `SET ECHO ON;`: Displays the SQL commands on the screen as they are executed.
*   `SET SERVEROUTPUT ON;`: Enables the retrieval and display of output generated by PL/SQL blocks (via `DBMS_OUTPUT`).

---

## Database Objects

### Tables

#### `github_projects`

A sample table used to store metadata about software projects.

| Column Name | Data Type | Constraints / Default | Description |
| :--- | :--- | :--- | :--- |
| `project_id` | `NUMBER` | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | Unique identifier for each project, auto-incremented by default. |
| `project_name` | `VARCHAR2(100)` | `NOT NULL` | The name of the project. |
| `language` | `VARCHAR2(50)` | *None* | The programming language used in the project. |
| `created_date` | `DATE` | `DEFAULT SYSDATE` | The timestamp when the record was created. Defaults to the current system date. |
